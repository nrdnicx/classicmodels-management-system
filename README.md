# ClassicModels Management System



A web-based business management application built with Node.js, Express.js, EJS, and MySQL.



## Features



- Dashboard for accessing business information

- Customer management pages

- Employee information pages

- Sales-related module

- MySQL database connectivity

- Dynamic web pages using EJS templates



## Technology Stack



- Backend: Node.js and Express.js

- Frontend: HTML, CSS, JavaScript, EJS

- Database: MySQL

- Tools: Visual Studio Code, npm, Nodemon



## Purpose



This project demonstrates backend web development, database integration, Express routing, and server-side rendering.
